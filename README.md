# Эвакуатор Джанкой

Сайт эвакуатора из Джанкоя: круглосуточно, по городу 2 500 ₽ за весь выезд, межгород и через Крымский мост 150 ₽ за км.

Адрес: https://mmaemi77-ctrl.github.io/Evakuator_top/

## Как поменять данные

Цены, номер WhatsApp и счётчик Яндекс Метрики лежат в начале скрипта в `index.html`, в объекте `TOW`:

```js
const TOW={
  wa:"79785442676",   // номер WhatsApp без плюса
  cityPrice:2500,     // весь выезд по Джанкою, ₽
  perKm:150,          // межгород и через мост, ₽ за км
  metrika:""          // номер счётчика Яндекс Метрики
};
```

Цены в тексте страницы (первый экран, тарифы, шаги вызова), в описании для поиска и в `evakuator-dzhankoy.vcf` меняются отдельно, поиском по «2 500» и «2500».

## Цели для Метрики

Сайт отправляет события: `call`, `whatsapp`, `telegram`, `calc_whatsapp`, `geo_whatsapp`, `geo_fallback`, `save_contact`, `avito`.
